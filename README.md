# Cesta de Farmácias

Página que compara preços de remédios em Araújo, Droga Raia, Pacheco, Drogasil e Ultrafarma.

Este repositório guarda só o código da página. A lista de compras e a chave de acesso ficam
salvas apenas no aparelho de quem usa; as buscas são feitas por um robô num repositório privado.
