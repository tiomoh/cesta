Chave do GitHub

A página usa uma chave para pedir ao robô do seu repositório que faça as buscas. A chave fica guardada só neste aparelho.

  1. Toque em Criar chave no GitHub (o formulário já vem preenchido).
  2. Em Repository access, escolha Only select repositories e marque DrugstoreComparison.
  3. Confira em Permissions: Actions: Read and write e Contents: Read-only.
  4. Toque em Generate token, copie a chave (começa com github_pat_) e cole abaixo.
